# 拍照生成接口草案

## 状态与用途

本文在整合时汇总“虚构网络与目标系统”和“AI 接入与生成系统”两边现有的摄像头及接口讨论，作为后续并行开发的共同起点。当前没有摄像头实现、生成任务接口或外部服务接入；字段和动作是建议，尚未完成接口定稿或联调。

用户已确认固定机位、玩家明确拍照才生成，以及未来接入 DeepSeek 与 ComfyUI。拟采用的链路为：摄像头验证访问条件并冻结画面事实，AI 方向通过 DeepSeek 整理提示词，再用 ComfyUI 生成并保存照片。设备细节见 [固定摄像头设计](fixed-camera-design.md)，共同原则见 [项目方向](project-vision.md)。

## 职责与流程

1. 虚构网络方向检查设备是否可达、身份和拍照权限。
2. 设备创建拍摄标识，冻结拍摄时刻、固定机位、场景版本和当前可见事实。
3. AI 方向接收快照，建立异步生成任务，负责提示词、工作流与外部调用。
4. AI 方向保存生成结果，返回可读取的图片资源标识。
5. 虚构网络方向把图片资源关联到原拍摄记录；查看和保存的玩家交互与软件或浏览器方向配合实现。

网络方向负责世界状态、权限和拍摄记录；AI 方向负责生成任务及图片资源。图片生成失败影响本次拍照任务，设备在线状态仍由虚构网络的设备状态决定。

## 建议的输入

一次提交至少包含以下信息，具体字段名称、类型和版本规则由后续实现确定：

| 信息 | 用途 |
| --- | --- |
| 拍摄标识、摄像头标识 | 关联任务、拍摄记录与去重 |
| 拍摄时的世界时间 | 对应按下拍照时的场景，不采用生成完成时间替代 |
| 场景标识及版本 | 稳定定位房间、布局和外观定义 |
| 固定机位及成像设置 | 描述视野、画幅和必要的成像效果 |
| 可见事实 | 本次拍摄中可见的人物、物品、灯光、门窗等状态 |
| 必须保持的画面约束 | 说明与世界或线索相关的构图、数量和位置 |
| 参考素材标识及版本 | 引用可稳定读取的基准图和其他素材 |

拍摄记录应保留快照，或保留能够稳定恢复该快照的场景与素材版本。设备密码、镜头外的信息和其他无关秘密不属于图片生成上下文。世界时钟如何推进尚未确定，接口实现不能预先假定它等同现实时间。

## 建议的任务与结果接口

| 动作 | 约定 |
| --- | --- |
| 提交拍摄 | 接收快照，返回任务标识；输入不合法时返回明确原因 |
| 查询任务 | 返回排队、生成中、完成、失败或状态待确认等状态 |
| 取得图片资源 | 完成后返回资源标识，并提供图片内容、格式与必要尺寸信息的读取方式 |
| 重试 | 对已确认失败的任务沿用原拍摄标识和冻结快照，记录本次尝试 |
| 取消 | 可作为后续能力；区分游戏停止等待与远端任务实际停止 |

设备功能应使用项目的任务与资源接口；DeepSeek 消息格式、ComfyUI 工作流、队列标识和服务配置由 AI 方向处理。真实密钥与宿主路径不作为游戏内照片地址返回；导出到虚构电脑时通过受限文件系统接口完成。

## 去重、重试与断线

- 相同拍摄标识、相同快照的重复提交应关联已有任务，不新增游戏内拍摄记录。
- 相同拍摄标识对应不同快照时报告冲突。玩家明确再次拍照才创建新的拍摄标识。
- 生成等待期间即使世界发生变化，本次任务及其重试仍使用原来的快照。
- 已完成照片重新打开时读取保存的原图，不重新生成。
- 提交后断线而无法确定远端是否接收时，标为状态待确认，先恢复或查询；不直接按普通失败自动重复提交。

本地请求去重不能证明外部服务只执行过一次。远端是否支持查询、恢复或去重，需要按实际服务能力验证，不能预先承诺一次且仅一次的外部生成。

## 持久化与画面事实

拍摄记录关联快照、任务状态与图片资源；AI 方向保存生成结果和必要的生成版本资料。预设场景、参考素材与工作流模板纳入资源管理；玩家运行状态和生成后的图片保存到被 Git 忽略的运行数据中，具体目录与迁移规则在实现时确定。

DeepSeek 可以根据已提供的场景决定如何描述画面，人物是否在场、门窗状态等世界事实由程序提供。模型生成的描述或图像不自动改变世界状态。结构化输出需要检查，字段正确也不保证图片准确表现人数、家具位置或文字。

与关键线索有关的视觉细节需要样本验证；必要时使用固定素材或独立合成，具体方法由后续任务确定。

## 并行开发与验收建议

网络方向可以先使用开发用的模拟图像服务完成拍照、失败、重试和记录保存；AI 方向后续提供真实生成接口。模拟服务和演示图片需要明确标识，不作为真实 ComfyUI 接入的验证结果。

后续联调应覆盖两次拍照之间发生事件、重试沿用原快照、重复提交不新增记录、断线后状态恢复、生成失败不改变设备在线状态，以及重启后能够继续读取已保存的照片。
