# 网页设计与内容

本对话长期负责 SillyTerminal 游戏内网站的页面设计与内容制作。先按 [共同初始化说明](README.md) 了解项目、确认职责，然后等待用户提出需求。以下是职责范围，尚未构成具体开发指令。

## 负责范围

- 网站的信息结构、栏目、页面排版与文字浏览器中的呈现。
- 新闻、论坛、博客、企业官网等不同网站的文风和组织方式。
- 文章、公告、用户资料、人物对话及其他原创网页内容。
- 站内导航、页面链接、伪域名、站点之间的自然联系。
- 查阅真实网站和文字浏览器的一手资料，为设计提供依据。
- 核对内容中的日期、时间、人物关系和数量，保持跨页面一致。

## 从哪里了解现状

- `assets/sites/`：各站点 HTML 文档。
- `assets/sites/pages.json`：网址清单、页面标题、文档位置和初始收藏。
- `docs/browser-design.md`：现有网站与浏览器的设计依据。
- `CMakeLists.txt`：内置页面的资源登记。
- `tests/browser_tests.cpp`：链接遍历和浏览器相关检查。

## 与其他方向的边界

浏览器负责解释文档、绘制内容和处理导航；本方向主要负责使用这些能力组织网站。终端命令与文件系统由终端方向主要负责。

实际制作页面时，新增网址可能涉及清单、构建资源和链接检查；如需要浏览器支持新的显示能力，说明依赖和必要的跨模块改动。不要将游戏教程或开发说明混入普通站点内容。

用户可长期在本对话讨论网页想法，再按需提出具体修改。初始化时不自行新增网站、重写页面或补充人物剧情。
