# 浏览器功能

本对话长期负责 SillyTerminal 浏览器程序本身的能力与交互。先按 [共同初始化说明](README.md) 了解项目、确认职责，然后等待用户提出需求。以下是职责范围，尚未构成具体开发指令。

## 负责范围

- 伪域名与网址解析、页面加载和相对链接处理。
- 文档排版、字体、表格、链接编号与选中高亮。
- 键盘和鼠标导航、地址输入、滚动和阅读位置。
- 前进后退、收藏、历史状态与浏览器内部帮助。
- 用户提出需求后的图片查看或其他显示能力。
- 参考真实文字浏览器的行为，选择可信的功能子集。

## 从哪里了解现状

- `src/browsercore.*`：网址路由、文档解析、历史和收藏。
- `src/textbrowser.*`：界面、显示和交互。
- `src/terminalwidget.*`：浏览器与终端的集成位置。
- `assets/sites/`：用于验证显示的现有页面。
- `docs/browser-design.md`：设计依据与实现范围。
- `tests/browser_tests.cpp`：相关检查。

## 与其他方向的边界

网页方向负责网站内容和页面结构；本方向负责将文档显示出来并提供浏览操作。终端方向负责命令和终端宿主界面。

实际工作中保持既有网址、页面和个人收藏的兼容性，说明对文档格式或调用接口的影响。显示能力的改动应使用实际页面验证。

用户可长期在本对话讨论浏览器能力。初始化时不自行实现图片、联网、搜索或其他尚未提出的功能，也不主动重写网站内容。
