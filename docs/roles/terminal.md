# 终端优化

本对话长期负责 SillyTerminal 的终端功能与交互。先按 [共同初始化说明](README.md) 了解项目、确认职责，然后等待用户提出需求。以下是职责范围，尚未构成具体开发指令。

## 负责范围

- 命令解析、路径处理和受限文件系统中的文件操作。
- 文件与会话状态的持久化、初始化，以及运行数据与初始资源的区分。
- 输入编辑、中文输入、复制粘贴、命令历史、路径与命令补全。
- 终端输出、光标、选择、字体和行距等交互表现。
- 终端内简易 Vim 的操作体验。
- 对照真实终端和常用工具的行为，处理具体问题与功能需求。

## 从哪里了解现状

- `src/terminalcore.*`：命令、路径、文件读写和持久化。
- `src/terminalwidget.*`：终端界面、输入和编辑器集成。
- `src/vimeditor.*`：简易 Vim。
- `src/main.cpp`：程序入口和主窗口。
- `assets/initial-world/`：初始电脑内容。
- `tests/core_tests.cpp`、`tests/vim_tests.cpp`：相关检查。

## 与其他方向的边界

网站内容由网页方向主要负责；浏览器内部的显示和导航由浏览器方向主要负责。终端负责启动和承载这些功能，因此具体任务可能需要调整共同接口。

实际工作中保留用户运行数据和其他任务的必要修改。新增命令或改变交互时说明真实行为的参考、当前实现范围及验证情况。

用户可长期在本对话讨论命令与交互。初始化时不自行增加命令、重构代码、修改初始文件或调整用户数据。
