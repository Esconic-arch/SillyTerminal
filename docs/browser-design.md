# 文字浏览器与网站设计依据

## 原则与范围

真实感优先。简易版本缩减功能范围，保留的行为参照真实软件。此版本实现可阅读、可导航的离线网站：普通网址、正文链接、前进后退、收藏、滚动与内部帮助。未加入登录、搜索、发帖、下载及对应入口。

页面来自独立的 HTML 文档，使用格式良好的 XHTML 子集。浏览器统一字号、字体、链接编号与选中表现；站点通过文档结构体现差异。当前 Qt Widgets 实现是一种模拟，没有集成完整的 Lynx/w3m 引擎，也不具备通用网络、HTML、CSS 或 JavaScript 支持。

## 参考资料

- [Lynx 用户指南](https://lynx.invisible-island.net/lynx_help/Lynx_users_guide.html)：选中链接高亮，方向键与回车导航，独立的帮助和收藏。
- [Lynx 编号链接说明](https://lynx.invisible-island.net/lynx2.8.9/lynx_help/keystrokes/follow_help.html)：编号链接、输入多位链接编号后确认。本项目使用底部输入提示，允许取消。
- [w3m 官方介绍](https://w3m.sourceforge.net/)与 [FAQ](https://w3m.sourceforge.net/FAQ.html)：HTML 在终端中的文字排版、Tab 切换链接、网址输入、收藏与独立操作界面。
- [Links 功能说明](https://links.twibright.com/features.php)：文字模式中的表格、链接、颜色与可选鼠标操作。表格结构在本项目论坛列表及新闻时刻表中使用。
- [Hacker News](https://news.ycombinator.com/)：实际网站的紧凑导航、标题链接、作者与活动信息；讨论页显示用户、时间及回复关系。借鉴信息组织，未复制文章、用户身份或讨论内容。

以上是设计依据，界面布局为本项目的取舍，不声称复刻任何特定浏览器。

## 交通运营官网

“环城轨道交通”使用伪域名 `www.hcmetro.com`，未加入初始收藏。采用普通运营企业网站的栏目组织：首页、线路与时刻、车站信息、运营公告。既可直接输入地址，也可从 Daybreak 报道中的来源链接访问。

结构参考 [港铁服务时间](https://www.mtr.com.hk/ch/customer/services/train_service_index.html)对运行方向、首末班与时段间隔的区分，以及 [TfL 地铁服务页面](https://tfl.gov.uk/modes/tube/)将时刻、服务调整和无障碍信息分别列出的做法。站名、企业、班次和公告内容均为游戏原创，未接入真实运营数据。

首期仅展示环线、南桥站与两则公告，未增加行程搜索、实时到站或售票入口。跨午夜的末班使用“次日”表述，并注明所属运营日；报道、时刻表、公告和车站出入口时间保持一致。首页标注资料更新日期，不使用伪造的实时运行状态。

## 内容约束

论坛主题列表的回复数应等于正文中楼主之外的帖子数，最后回复人与时间应一致；用户资料的帖子数与参与主题应能对应现有内容。网页日期属于虚构世界的静态时间，页面注明日期，不冒充当前真实新闻。

人物保留稳定的兴趣、经历与语气。对话允许误解、调侃、短回复和跑题，也有普通求助和认真回答。新闻使用事实、署名、更正和实用信息；博客保留个人记录的随意程度。操作教程与开发说明只出现在浏览器帮助和项目文档中。

## 检查

自动测试遍历所有内置链接，检查页面可达、网址兼容、收藏持久化、表格与行内链接、多位编号跳转、帮助入口和返回阅读位置。界面截图检查列表页、帖子页、新闻、博客和收藏页，避免大标题、过量留白或无效入口。
