# 本地图像查看器首版

提供 `feh [--] [文件或目录 ...]`，在游戏应用内实现 feh 的本地查看功能子集。它是独立的 `image_viewer` 模块，当前可以直接启动；通用获取、软件包、安装和卸载仍待统一设计。本轮不调用宿主 feh、不启动外部程序、不访问互联网，也不触发摄像头拍照或图像生成。

## 依据与范围

交互参考 [feh 官方手册](https://man.finalrewind.org/1/feh/) 的文件/目录参数、前后切图、缩放、原始尺寸、适应窗口、拖拽平移、重新载入以及退出方式。Qt 的 [QImageReader](https://doc.qt.io/qt-6/qimagereader.html) 负责真实图片解码和 EXIF 显示方向。

首版支持 PNG、JPEG 静态图片。可以指定单个文件、多个文件或多个目录；不带参数使用终端当前目录。目录仅枚举直接子文件，按名称排序，筛选 `.png`、`.jpg`、`.jpeg`（不区分大小写），跳过子目录和符号链接/目录联接。显式指定的文件按内容识别格式，因此其他扩展名的有效 PNG/JPEG 仍可通过命令打开。多个参数按给出顺序展开，重复路径只保留一次。

画面显示文件路径、图片尺寸、格式、当前序号、总数及缩放比例。透明区域显示棋盘背景；图片首次打开和切换时适应当前查看区域，放大最多3200%。前后导航循环经过启动时的列表。缺失或无效项显示具体错误，仍可切换至其他项。

| 操作 | 按键/入口 |
| --- | --- |
| 下一张 | Right、Space、n、Next；滚轮向上 |
| 上一张 | Left、Backspace、p、Previous；滚轮向下 |
| 放大/缩小 | Up / Down、工具栏 + / −；Ctrl+滚轮 |
| 适应窗口 | `/`、Fit |
| 原始尺寸 | `*`、100% |
| 平移 | 鼠标左键拖拽；Ctrl+方向键 |
| 重读当前图片 | `r`、Reload |
| 帮助 | F1、Help |
| 退出 | q、Esc、Close；帮助打开时 Esc 先关闭帮助 |

Ctrl+滚轮和按钮栏是本项目承载方式的补充。首版不实现真实 feh 的全部命令行选项、X11 功能、自动幻灯片、缩略图、动画、编辑、删除、保存副本、远程 URL、外部动作和自定义按键配置。只读查看不创建配置文件或修改图片。

## 真实文件与外部改动

图像读取通过 `TerminalCore::readBinaryFile`，沿用同一套受限世界路径与文件类型检查。摄像头导出至 `runtime/world/` 的 PNG/JPEG，以及玩家在游戏外放入该目录的真实图片，都可直接使用。

- 打开、切换图片及 Reload 时，重新打开磁盘文件并解码；当前画面在此之前保留读取时的快照，不自动监听文件变化。
- Reload 成功时保留手动缩放和视图中心；适应窗口模式重新计算大小。
- 文件删除、替换为不支持的内容、损坏或超过限额时，清除旧画面并显示错误。文件恢复后可以再次 Reload，不使用旧画面冒充新文件。
- 目录列表在启动时枚举。外部新增图片需要重新打开目录后出现；Reload 仅重新读取当前文件。列表中已删除的图片在再次读取时显示错误，不自动重建文件。
- 查看器不回写源文件，无编辑保存冲突；关闭查看器不删除文件。终端目录、历史输出与 mc 面板状态保留。

首版每个文件最多 20 MiB，解码尺寸最多单边 16384、总计 32000000 像素。文件读取本身有限额，解码前检查尺寸，避免仅按磁盘文件大小判断图片内存需求。

## mc 与终端衔接

终端增加命令、补全、帮助及交互程序承载。`feh` 不接受管道或输入输出重定向，拒绝时不会预先创建输出文件。

mc 新增通用 `viewFile(path)` 宿主回调：宿主为 PNG/JPEG 文件名打开查看器，其他文件沿用文本分页器。Enter、双击、F3 使用同一查看入口；F4 仍走文本 Vim。查看器退出后返回原面板、选中项和标记。mc 不依赖图像查看器的解码实现。

## 验证

`tests/image_viewer_tests.cpp` 使用临时世界和真实 PNG/JPEG 测试文件，覆盖命令、路径、二进制读取限额、格式识别、缩放/平移/最小窗口、文件列表、只读行为、外部替换/删除/损坏/恢复，以及终端和 mc 的嵌套启动与返回。不调用真实 AI 服务。预览图片 `image-viewer-preview.png` 中的接线图属于测试夹具，不是正式游戏内容。

Windows 与 macOS 使用同一实现；实际平台验证范围见本轮交付说明。
