# Midnight Commander 首版

本轮提供 `mc [目录 [另一侧目录]]`，作为游戏内的双栏文件管理器。它使用同一套 C++ / Qt 源码，功能单独放在 `mc_file_manager` 模块中；不调用宿主系统的 mc 或 Shell。当前可直接启动，获取、软件包、安装与卸载机制仍待统一设计。

## 真实软件依据与实现范围

参考 GNU Midnight Commander 的[官方手册](https://source.midnight-commander.org/man/mc.html)：双栏文件列表、Tab 切换、Insert 标记、F3 查看、F4 编辑、F5 复制、F6 移动、F7 建目录、F8 删除、F10 退出，以及 `mc [dir1 [dir2]]` 的启动方式。窗口使用经典蓝色面板、青色选中行、黄色标记和功能键栏，省略未实现的 F2 用户菜单和 F9 菜单。

首次两侧均从终端当前目录开始；给出路径时先验证目录。退出时将非活动面板目录写入虚构文件 `~/.config/mc/panels.ini` 的 `[Dirs] other_dir`。再次启动时活动面板从终端当前目录开始，另一侧恢复保存的目录；显式第二个路径优先。已失效的保存路径不使用。保存失败时说明原因，允许取消退出或不保存退出。文件操作立即落盘，软件操作不进入终端命令历史。退出不改变终端当前目录。

支持 UTF-8 文本查看和编辑：F3 复用现有分页器，F4 使用现有 Vim 作为外部编辑器。这符合真实 mc 可配置外部查看器和编辑器的方式；没有声称实现 mcedit。阅读、编辑退出后返回原面板、位置与标记。二进制文件可以按原字节复制和移动，查看和编辑时给出不支持的反馈。

F5 / F6 的目标默认是非活动面板，可填写绝对路径、相对于活动面板的路径或 `~` 路径。支持目录递归和 Insert 多选；多选要求目标是已有目录。已有目标不会覆盖，也不合并目录，需换名或先处理目标。这是首版明确限定，真实 mc 的覆盖确认、目录合并与文件掩码暂未实现。批量操作遇错停止，保留已完成结果，显示完成数量和错误，保留未处理项的标记。

F8 删除前显示确认，默认焦点为取消，明确说明目录包含其全部内容。目录列表被外部修改时，可用 Ctrl+R 刷新；失效的面板目录回退到仍可访问的父目录。Alt+C 打开切换目录输入，Alt+. 切换隐藏文件；Alt+数字代替功能键，功能键栏亦可点击。窄窗口隐藏修改时间列，保留名称与大小。

本轮不提供 Shell 命令行、用户菜单、权限/所有者编辑、远程文件系统、归档浏览、文件掩码、执行文件、文件关联管理或通用插件系统。帮助内容放在 F1 软件帮助和项目文档中。

## 与终端的接口

`TerminalCore` 增加结构化的目录枚举、文本读取、复制、移动、删除和建目录接口，沿用现有路径验证、链接/目录联接限制、根目录与当前目录保护。mc 不直接访问宿主路径，也不将文件名拼成 Shell 命令。软件界面和批量操作逻辑位于独立模块；终端仅增加命令入口、帮助、补全与界面承载。

运行数据继续位于当前 worktree 的 `runtime/`；`panels.ini` 属于玩家文件的一部分，模板资源不因软件退出而改变。现有账户、浏览器和其他程序行为保持各自职责。

## 验证

`tests/mc_tests.cpp` 使用临时世界，检查启动路径、补全、管道/重定向拒绝、合法文件名中的中文/空格/单引号/与号/括号、非法文件名拒绝、二进制复制、递归操作、标记批量处理、取消、同名冲突、错误反馈、重启持久化、受限路径以及终端/分页器/Vim/文件管理器之间的返回。测试输出 `mc-preview.png` 供界面检查。

Windows 与 macOS 采用同一实现；本轮实际验证范围以任务交付记录为准。
